# Список прокси для DashScope API Key Checker.
# Скопируйте этот файл в proxies.txt, раскомментируйте/впишите свои прокси
# и загрузите его в поле «Прокси» кнопкой «📁 Из файла».
#
# Формат: по одному прокси в строку.
# Пустые строки и строки, начинающиеся с #, игнорируются.
# Поддерживаемые схемы: http, https, socks4, socks4h, socks5, socks5h.
# Строка без схемы считается HTTP-прокси.
# socks5h = SOCKS5 с разрешением DNS на стороне прокси (рекомендуется).
# Для SOCKS нужен PySocks: pip install "requests[socks]"
#
# Примеры (уберите # и подставьте свои данные):
# http://127.0.0.1:8080
# http://user:password@1.2.3.4:8080
# socks5://127.0.0.1:1080
# socks5h://user:password@5.6.7.8:1080
# 9.10.11.12:3128
